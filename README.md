# Desktop Snow

Снегопад для рабочего стола Windows 10 (2004 и новее) и Windows 11, x64. Снег ложится на окна, осыпается при их сворачивании и реагирует на курсор. Вдохновение — [Snowhush](https://github.com/mbezruchko/Snowhush).

## Как запустить

1. Если на компьютере ещё нет **.NET 8 Desktop Runtime x64**, установите его с [сайта Microsoft](https://dotnet.microsoft.com/en-us/download/dotnet/8.0).
2. Скачайте **DesktopSnow.exe** из блока **Assets** на странице [последнего релиза](https://github.com/Nikita1512russs/DesktopSnow/releases/latest).
3. Запустите скачанный файл. Дополнительный установщик для Desktop Snow не нужен.

## Как пользоваться

<ins><strong>По умолчанию включён режим «Снизить нагрузку на ПК». Чтобы отключить его, снимите галочку в настройках и нажмите «Применить».</strong></ins>

- Нажмите значок снегоуборщика на панели задач или в трее, чтобы открыть настройки. Там можно изменить интенсивность, прозрачность и интервал проезда снегоуборщика. **«Применить»** сохраняет настройки.
- Проведите курсором по сугробу, чтобы разгрести снег. Для лепки нажмите **«Слепить снеговика»**, зажмите левую кнопку мыши и прокатите комок по накопившемуся снегу. Сложите три комка друг на друга. **Esc** завершает лепку.
- Снежинки видны на свободном рабочем столе и по бокам окон. Окно прикрывает от снегопада полосу под собой. Когда весь экран занят, слой снега скрывается.
- Кнопка **«−»** сворачивает настройки. Кнопка **«×»**, пункт **«Выход»** в трее и команда **«Закрыть окно»** на панели задач завершают приложение.

## Сборка из исходников

На Windows с установленным .NET 8 SDK:

```powershell
dotnet run --project .\DesktopSnow.csproj -c Release
dotnet publish .\DesktopSnow.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=none -o dist
dotnet run --project .\tests\DesktopSnow.Checks.csproj -c Release
```
